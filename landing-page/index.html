COMMON QUESTIONS

Frequently Asked Questions

How does the companion run on my specified laptop? +
The installer registers your laptop's machine identifier and hardware profile. It configures the local FastAPI orchestrator and Electron desktop window to automatically dock right above your Windows taskbar.
What happens if an app like Spotify or YouTube isn't installed? +
That is the strength of JM Vertex's Smart Multi-Path Fallback! If Spotify or YouTube desktop apps are missing, it instantly detects your installed browser (Google Chrome, Edge, or Brave) and launches the official web application without failing.
Does it block my mouse clicks or desktop work? +
No. The avatar window features transparent click-through capabilities. You can click on any folders, icons, or background windows underneath the companion without accidental interference.
Does it require an active internet connection? +
The Faster-Whisper speech engine and native Windows application launching operate 100% locally and offline. An internet connection is only needed when using web fallbacks (e.g. streaming YouTube or online search).
